# Smart Irrigation Using AI and IoT

## Tags

`IoT` `Sensors` `Agriculture` `Machine Learning`

## Problem

Over-watering wastes water. Under-watering kills crops. Manual irrigation is imprecise.

## Solution

Predict watering needs from soil and weather data.

### Features

- Soil moisture monitoring
- Weather API integration
- ML-based watering prediction
- Automated valve control
- Mobile dashboard

## Society Impact

- Water conservation
- Better crop yields
- Reduced farming labor
- Applicable to small farms and greenhouses

## Environmental Impact

- Significant water savings
- Less fertilizer runoff
- Lower energy for water pumping

## Feasibility

- ✅ Soil sensors ($3-10)
- ✅ Arduino + relay + solenoid valve
- ✅ Weather API (OpenWeatherMap)
