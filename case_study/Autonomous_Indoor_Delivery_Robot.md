# Autonomous Indoor Delivery Robot

## Rating: ⭐⭐⭐⭐

## Tags

`SLAM` `Navigation` `PID` `Robotics` `Computer Vision` `Embedded`

## Problem

Hospitals and factories waste thousands of worker-hours moving supplies. Nurses spend time transporting medicine instead of caring for patients.

## Solution

A robot that navigates indoors while avoiding obstacles and delivering small items.

### Technologies

| Component | Technology |
|-----------|------------|
| Navigation | SLAM (Simultaneous Localization and Mapping) |
| Vision | Computer Vision (camera-based) |
| Distance | Ultrasonic / LiDAR sensors |
| Control | PID controller |
| Platform | Arduino / Raspberry Pi + motor drivers |

### Features

- Map indoor environments
- Plan optimal delivery routes
- Avoid dynamic obstacles (people, carts)
- Return to base for charging
- Remote monitoring via web interface

## Society Impact

- Hospitals become more efficient
- Workers focus on skilled work (not transportation)
- Useful for: hospitals, warehouses, universities, factories

## Environmental Impact

- Electric robots use less energy than larger transport vehicles
- Reduce unnecessary human travel inside large facilities
